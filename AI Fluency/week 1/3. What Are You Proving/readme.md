## 🚀 Selected Works Showcase

### 1. Brain Tumor Detection with Gesture Control
* **Tech Stack:** Python, FastAPI, CNN, ResNet18, React
* **Description:** A custom-trained CNN (ResNet18) detects tumors from medical imaging, deployed behind a FastAPI backend and a React frontend — with a touchless gesture-control interface layered on top for sterile-environment use.

### 2. Road Accident Detection System
* **Tech Stack:** CNN, FastAPI, PyTorch, React
* **Description:** A custom CNN processes live video frames in real time via FastAPI to detect road anomalies and accidents, surfaced through a React interface.

### 3. Smart Dining Assistant
* **Tech Stack:** Next.js, LangChain, Groq, Express.js
* **Description:** An LLM-orchestrated in-app ordering assistant (Zara), demonstrating full-stack integration of generative AI into a production-style user flow.
