# General AI Fluency · Impact Project Capstone Submission

## 1. How to Add the Next Case Study

To keep the portfolio as a living career platform rather than a static class artifact, future case studies will be added through a standardized, repeatable workflow.

### Step 1: Add the Project to the Portfolio

Create the new case study using the same component and page structure as an existing project. Add the project page under the portfolio's project structure and register the new project in the main project configuration so it appears in the portfolio grid.

### Step 2: Use the Three-Beat Case Study Structure

Every new case study will follow the Week 2 narrative framework:

* **The Problem:** Clearly explain the clinical, technical, or real-world friction the project is solving.
* **What I Did:** Describe the architecture, AI/model choices, implementation, engineering decisions, and UI/UX approach.
* **What Came of It:** Document measurable outcomes, performance results, evaluation findings, screenshots, live validation, or a working demo link.

This keeps each project focused on the problem, the work performed, and the impact produced.

### Step 3: Update the Ayush Orbit Knowledge Base

After adding the case study, update the context used by **Ayush Orbit** with the new project's:

* Name and purpose
* Problem being solved
* Technology and architecture
* Key implementation details
* Results and validation
* Repository and live-demo information

This ensures the conversational agent can answer questions about the new project without requiring the portfolio to be rebuilt from scratch.

### Step 4: Validate and Deploy

Before publishing the update:

1. Run the project locally and verify the new case study.
2. Run the production build and fix any errors.
3. Test the project navigation and Ayush Orbit responses.
4. Commit and push the changes to GitHub.
5. Verify the automated Netlify deployment.
6. Check the live portfolio and confirm that the new case study is accessible.

### Case Study Checklist

* [ ] Project page created
* [ ] Project added to portfolio grid
* [ ] Problem documented
* [ ] Work/implementation documented
* [ ] Results and validation documented
* [ ] Ayush Orbit context updated
* [ ] Local build verified
* [ ] GitHub changes pushed
* [ ] Netlify deployment verified
* [ ] Live portfolio tested
