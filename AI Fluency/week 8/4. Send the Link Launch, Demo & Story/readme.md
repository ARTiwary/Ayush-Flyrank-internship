## How to Add the Next Case Study

The next case study will be added to the existing portfolio repository as a new project card and case study page, following the same structure and visual style as the current projects.

### Steps

1. **Duplicate an Existing Project**

   * Copy the component structure of an existing project card or case study page in the portfolio repository.
   * Rename the project and replace the existing content with the new project's information.
   * Keep the existing portfolio layout, navigation, and styling consistent.

2. **Use the Three-Beat Case Study Structure**

   Each new case study will follow the same structure used in Week 2:

   **The Problem** — Explain the clinical, technical, or real-world problem and the friction that needed to be solved.

   **What I Did** — Describe the solution, architecture, implementation, AI tools, code, and important engineering decisions.

   **What Came of It** — Show the result using measurable outcomes, performance improvements, validation results, screenshots, or a link to the working project/demo.

3. **Update the AI Knowledge Base**

   * Add the new project information to the **Ayush Orbit** system prompt and relevant context/knowledge files.
   * Include the project's purpose, technology stack, implementation details, and results.
   * This will allow the portfolio's conversational AI agent to answer recruiter or visitor questions about the new case study.

4. **Deploy the Updated Portfolio**

   * Commit and push the changes to GitHub.
   * The portfolio will be automatically deployed through Netlify.
   * Verify the live case study page and test that the Ayush Orbit assistant can answer questions about the new project.

### Case Study Checklist

* [ ] Project card added to the portfolio
* [ ] Case study page created

* [ ] Implementation and engineering decisions documented
* [ ] Results/metrics/demo included
* [ ] Ayush Orbit knowledge base updated
