Here's the concrete path, broken into two options depending on what you're using. Pick whichever is easier for you.

## Option A: claude.ai connectors (no install, easiest)

1. Go to claude.ai → **Settings → Connectors**.
2. Click **Browse connectors** (or "Add more") and connect something simple — **Google Drive** or **GitHub** are good picks since they clearly can't be done by chat alone.
3. Once connected, toggle it **on** for your current chat (there's usually a small tool/connector icon in the chat box to enable it per-conversation).
4. Run the three tasks as normal messages:
   - Task 1 (GitHub): *"Pull the latest commit on my Ayush-Flyrank-internship repo and tell me what changed."*
   - Task 2 (GitHub): *"List the files inside the FL-04 folder in that repo."*
   - Task 3 (Google Drive, if connected): *"Find any doc in my Drive related to FL-04 and summarize it."*
5. Screenshot each response — make sure the screenshot shows the little "used [connector name]" tool-call indicator that appears above/below the answer, not just the text. That indicator is your proof it wasn't answered from memory.

## Option B: Claude Desktop with filesystem MCP server (if you have it installed)

1. Open Claude Desktop → **Settings → Developer → Edit Config** (or find `claude_desktop_config.json` directly — on Windows it's in `%APPDATA%\Claude\`, on Mac `~/Library/Application Support/Claude/`).
2. Add this block (edit the path to your actual FL-04 folder):
```json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/path/to/your/FL-04/folder"]
    }
  }
}
```
3. Save, fully quit and reopen Claude Desktop.
4. Confirm it loaded: you should see a hammer/tools icon in the chat box, and clicking it should list filesystem tools (`read_file`, `list_directory`, etc.).
5. Run the three tasks:
   - *"List every file in my FL-04 project folder."*
   - *"Read readme.md from that folder and summarize the pipeline in 2 sentences."*
   - *"Create a new file called test-note.txt in that folder with the text 'MCP works'."* (this one proves it can act, not just read)
6. Screenshot each — again, make sure the tool-call block is visible in the screenshot.
